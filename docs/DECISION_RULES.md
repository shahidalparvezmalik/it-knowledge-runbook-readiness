# Decision rules

Fixed checks flag missing fields, overdue/future review dates, invalid dates/intervals, unconfirmed owners, unconfirmed service mappings, and absent rollback/escalation guidance for high-risk records. Overdue means elapsed days are strictly greater than the supplied interval.

A clean result means only that these configured checks found no issue. It does not prove the procedure correct, safe, authorized, tested, or suitable for a live incident. Every record requires human review.

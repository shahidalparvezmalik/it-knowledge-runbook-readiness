# Data dictionary

`knowledge_id` fictional identifier; `title` descriptive label; `owner` accountable group/person; `owner_status` must be `confirmed`; `service` mapped service name; `service_status` must be `confirmed`; `last_reviewed` ISO date; `review_interval_days` review interval; `purpose` intended outcome; `preconditions` checks before use; `steps` guidance; `validation` success checks; `rollback_or_escalation` fallback/escalation; `audience` intended reader; `risk_level` optional label, with `high` triggering the rollback/escalation check. Fixture data is fictional.
